# Single-line font data

The JSON files in `data/` are generated by `scripts/build-single-line-fonts.mjs`
from the EMSL Hershey SVG fonts (prepared by Windell H. Oskay,
www.evilmadscientist.com, from emergent.unpythonic.net/software/hershey), as
distributed in the `hersheytext` npm package.

The Hershey Fonts license requires these acknowledgements to be distributed
with the font data:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working
  at the U. S. National Bureau of Standards.
- The format of the Font data in this distribution was originally created by
  James Hurt, Cognition, Inc., 900 Technology Park Drive, Billerica, MA 01821
  (mit-eddie!ci-dandelion!hurt).

The font data may be converted into any other format *except* the format
distributed by the U.S. NTIS, where each point is described in eight bytes as
"xxx yyy:", where xxx and yyy are the coordinate values as ASCII numbers.

The EMS fonts in the same package are under the SIL Open Font License. Before
adding one, include the OFL text and that font's copyright notice here.
